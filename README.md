# Rocker Furniture Store

A furniture-store homepage built with HTML and CSS as a front-end web development project. The design showcases furniture categories, promotional banners, service features, and featured product cards.

## Overview

This project recreates a furniture e-commerce landing page with a clean navigation bar and several visual sections. It focuses on practicing HTML page structure and CSS layout, styling, transitions, and hover effects.

## Features

- **Navigation bar:** Furniture categories and a dropdown menu.
- **Dropdown menu:** A multi-column menu displayed when hovering over the Furniture navigation item.
- **Hero banner:** A large furniture banner at the top of the page.
- **Special categories:** A grid of furniture category images and descriptions.
- **Promotional banners:** Discount banners with overlaid text.
- **Service section:** Service icons with hover effects.
- **Featured products:** Product cards with a 3D flip animation.
- **Product ratings and prices:** Star icons and sample product information.
- **Responsive styling:** CSS media queries for tablet and mobile layouts.
- **Interactive visual effects:** Transitions and hover states for selected elements.

> Note: This is a front-end practice project. The dropdown entries and product information are illustrative; the page does not currently implement a working shopping cart, product purchasing, or backend functionality.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS pseudo-elements
- CSS transitions and transforms
- CSS media queries
- Font Awesome icons

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
4. Hover over the Furniture menu and product cards to view the CSS effects.
